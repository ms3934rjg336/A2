# Halletts Point Community Planning Tool | A Digital Approach to Conventional Community Boards

**Submit Ideas • Annotate Plans • Vote & Fund Projects**

An interactive web-based community planning platform that empowers residents of Halletts Point, Astoria (Queens, NY) to propose, vote on, and fund neighborhood improvements through grassroots participation.

## About the Project

For too long, community planning has been a top-down process where residents are told what their neighborhood needs instead of being asked. The Halletts Point Community Planning (HPCP) tool changes that paradigm by putting planning power directly in the hands of community members.

This platform enables residents to visually annotate site plans, submit project proposals with budgets, vote on their neighbors' ideas, and contribute funding to make community visions a reality—like a neighborhood GoFundMe meets urban planning.

## Website Features

- **Visual Annotation Tools**: Draw directly on site plans with freehand sketching and sticky notes
- **Drag-and-Drop Elements**: Quick-add urban furniture items (benches, trees, playgrounds, bike racks, etc.)
- **Proposal Creation System**: Set project budgets, add descriptions, and upload reference photos
- **Community Voting**: Vote BUILD or DEMOLISH on proposals from neighbors
- **Grassroots Funding Portal**: Contribute directly to projects with a demo payment system
- **Interactive Image Carousel**: Navigate through 27 site plan views
- **User Authentication**: Sign-in system for voting and contributing
- **Retro Web Portal Aesthetic**: Early 2000s-inspired design language

## Platform Sections

1. **Home** — Landing page with top proposals and platform overview
2. **Create Proposal** — Interactive annotation interface for submitting new ideas
3. **Browse Proposals** — View and engage with community-submitted projects
4. **Our Mission** — Organization vision and community-driven planning philosophy
5. **Board Information** — Meet the planning board and meeting schedules
6. **Community Events** — Upcoming neighborhood activities and ongoing programs
7. **Meeting Minutes** — Official records and presentation downloads
8. **Resources** — Helpful links, local services, and site usage guides
9. **Become a Member** — Membership application form
10. **Contact Us** — General inquiries and issue reporting

## How It Works

1. **Create Proposal** — View site plans, draw your ideas, add notes & set a budget
2. **Community Votes** — Neighbors vote "Build" or "Demolish" on proposals
3. **Fund Together** — Contribute to make favorite projects happen

## Design Approach

The platform balances functionality with accessibility through:
- Intuitive drag-and-drop interface for non-technical users
- Transparent proposal process with public visibility
- Democratic voting system regardless of wealth or connections
- Direct funding mechanism bypassing traditional bureaucracy
- Nostalgic web portal aesthetic creating familiar, approachable UX

## Built With

- HTML5 / CSS3 / JavaScript
- Custom canvas-based annotation system
- Responsive web design
- Video integration for site documentation
